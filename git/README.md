# Git Fundamentals

## Project Overview

This project focuses on the fundamentals of Git, GitHub, and source code management.

The objective is to gain practical experience with version control, repository organization, basic file operations, and collaborative development workflows using the command line.

## Learning Objectives

- Understand source code management and version control.
- Explain the difference between Git and GitHub.
- Create, clone, and manage Git repositories.
- Track file changes using Git.
- Stage, commit, and push changes to a remote repository.
- Write clear and meaningful commit messages.
- Work with branches and understand merging.
- Pull updates from remote repositories.
- Organize project files and maintain documentation.
- Understand the purpose of `.gitignore` and `README.md` files.

## Tasks and Exercises

### Coding Fury Road

Practice creating and organizing a basic software development project with multiple programming languages.

The exercise includes:

- Creating directories for Bash, C, and JavaScript.
- Writing basic Bash scripts.
- Creating source code files.
- Tracking newly created files using Git.
- Committing changes with descriptive messages.
- Pushing local commits to GitHub.

### Git Workflow

Practice essential Git operations:

- `git clone` — Clone a remote repository.
- `git status` — Check the working directory status.
- `git add` — Stage changes.
- `git commit` — Record changes in the repository.
- `git push` — Upload local commits.
- `git pull` — Retrieve and integrate remote changes.
- `git branch` — Manage branches.
- `git merge` — Merge development branches.
